1扫码安装（安卓）

用手机相机 / 微信「扫一扫」扫描上方二维码
直接下载安装包（1.94 MB）
微信里扫出来打不开？点右上角「…」→ 选择「在浏览器打开」，再点下载即可。

2安装步骤

  1. 下载完成后点安装包 → 允许「安装未知来源应用」
  2. 点「安装」。如果手机里已有旧版，会直接覆盖升级
  3. 做题记录自动保留，不需要重新刷
  4. 装好之后，以后的更新在 App 内「我的 → 检查更新」即可，不用再装安装包

3iPhone 用户

苹果手机不需要安装包：用 Safari 打开网页版，点「分享 → 添加到主屏幕」，之后就像 App 一样用，且会自动更新。
